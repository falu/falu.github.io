**Hatályos:** 2026. május 31.

## 1. Az adatkezelő

Jelen weboldal (`falu.github.io`) üzemeltetője az adatkezelő. Az adatkezeléssel kapcsolatos kérdéseivel a [Kapcsolat oldalon](https://falu.github.io/kapcsolat/) keresztül fordulhat hozzánk.

## 2. Az adatkezelés alapelvei

Az adatkezelés során az Európai Parlament és a Tanács (EU) 2016/679 rendelete (GDPR), valamint az információs önrendelkezési jogról és az információszabadságról szóló 2011. évi CXII. törvény (Infotv.) rendelkezései szerint járunk el. Csak a szükséges adatokat kezeljük, kizárólag a megjelölt célból, az ahhoz szükséges ideig.

## 3. A weboldal tárhelye

A weboldal a **GitHub Pages** szolgáltatáson (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA) keresztül érhető el. A szolgáltató a weboldal megtekintésekor technikai adatokat (pl. IP-cím, böngészőadatok) naplózhat a szolgáltatás működtetése és biztonsága érdekében. Erről bővebben a GitHub adatvédelmi nyilatkozatában tájékozódhat: <https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement>

## 4. Kapcsolatfelvétel

Minden kapcsolatfelvétel a [https://falu.github.io/kapcsolat/](https://falu.github.io/kapcsolat/) oldalon keresztül történik.

- **Kezelt adatok:** az Ön által önkéntesen megadott adatok (pl. név, e-mail cím, üzenet tartalma).
- **Az adatkezelés célja:** a megkeresés megválaszolása, kapcsolattartás.
- **Az adatkezelés jogalapja:** az érintett hozzájárulása (GDPR 6. cikk (1) a) pont).
- **Az adatok megőrzési ideje:** az ügy elintézéséhez szükséges ideig, illetve a hozzájárulás visszavonásáig.

## 5. Hozzászólások (kommentek)

A weboldalon megjelenő hozzászólásokat (kommenteket) a **GitHub** tárolja és kezeli. A hozzászólás beküldésekor megadott adatok (pl. felhasználónév, profil, a hozzászólás tartalma) a GitHub rendszerében kerülnek rögzítésre, így azokra a GitHub adatvédelmi feltételei is irányadók.

- **Kezelt adatok:** GitHub-felhasználónév, profiladatok, a hozzászólás tartalma és időpontja.
- **Az adatkezelés célja:** a látogatók közötti kommunikáció, vélemények megosztása.
- **Az adatkezelés jogalapja:** az érintett hozzájárulása (GDPR 6. cikk (1) a) pont).
- **Adatfeldolgozó/tárhely:** GitHub, Inc. A GitHub adatkezeléséről itt tájékozódhat: <https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement>

A hozzászólás beküldéséhez GitHub-fiók szükséges, amelynek használatára a GitHub saját felhasználási és adatvédelmi feltételei vonatkoznak.

## 6. Sütik (cookie-k)

A weboldal a GitHub Pages működéséhez kapcsolódó technikai sütiket, valamint a hozzászólási funkció (GitHub) által elhelyezett sütiket használhat. Ezek egy része a szolgáltatás működéséhez elengedhetetlen. A böngészője beállításaiban a sütiket bármikor letilthatja vagy törölheti.

## 7. Adattovábbítás

Tekintettel arra, hogy a tárhely- és kommentszolgáltatást a GitHub (USA) biztosítja, az adatok az Európai Gazdasági Térségen kívülre is továbbításra kerülhetnek. A GitHub a megfelelő adatvédelmi garanciákról (pl. uniós általános szerződési feltételek) gondoskodik.

## 8. Az érintett jogai

Önt az alábbi jogok illetik meg személyes adatai kezelésével kapcsolatban:

- **hozzáférés** a kezelt adatokhoz,
- **helyesbítés** kérése,
- **törlés** ("elfeledtetéshez való jog") kérése,
- az adatkezelés **korlátozása**,
- **adathordozhatóság**,
- **tiltakozás** az adatkezelés ellen,
- a **hozzájárulás visszavonása** (amely nem érinti a visszavonás előtti adatkezelés jogszerűségét).

Jogai gyakorlására irányuló kérelmét a [Kapcsolat oldalon](https://falu.github.io/kapcsolat/) keresztül nyújthatja be.
